# HeadHunter Job Data Processing Project

Проект для сбора и анализа данных о вакансиях с платформы HeadHunter (hh.ru).

## 📁 Структура проекта
HeadHunter-HH.ru-Job-Data-Processing-Project/
├── src/
│ ├── main.py # Основной исполняемый файл
│ ├── config.py # Конфигурационные параметры
│ ├── hh_api.py # Модуль для работы с API HH.ru
│ ├── database.py # Модуль для работы с базой данных
│ └── dp_manager.py # Модуль для управления данными и запросов
├── requirements.txt # Зависимости проекта
└── README.md # Документация


## 🛠 Установка и настройка

1. Установка зависимостей

pip install -r requirements.txt

2. Настройка PostgreSQL

Убедитесь, что у вас установлен и запущен PostgreSQL. Создайте пользователя и базу данных, либо используйте стандартные настройки.

3. Настройка конфигурации

Отредактируйте файл src/config.py:

## 📁 Описание файлов

### main.py
Основной исполняемый файл приложения. Содержит:
- Инициализацию базы данных
- Загрузку данных через API HH.ru
- Сохранение данных в БД
- Интерактивное меню для работы с данными
Функциональность:
- Автоматическое создание БД и таблиц
- Загрузка данных о работодателях и вакансиях
- Интерактивное меню с 5 вариантами запросов

### config.py
Конфигурационный файл. Содержит:
- Параметры подключения к PostgreSQL
- Список ID работодателей для анализа
- Настройки базы данных
Важные параметры:
- DB_* - параметры подключения к PostgreSQL
- EMPLOYER_IDS - список компаний для мониторинга

### hh_api.py
Модуль для работы с API HeadHunter. Содержит:
Класс HeadHunterAPI:
- get_employers(employer_ids) - получение данных о работодателях
- get_vacancies(employer_id) - получение вакансий работодателя
Особенности:
- Пагинация запросов (по 100 вакансий за раз)
- Обработка ошибок HTTP запросов
- Преобразование JSON ответов в Python словари

### database.py
Модуль для работы с базой данных PostgreSQL. Содержит:
Класс Database:
- create_database() - создание новой БД
- create_tables() - создание таблиц employers и vacancies
- save_data(employers, vacancies) - сохранение данных в БД
- connect() - установление соединения с БД
Структура таблиц:
- employers: id, name, url, description
- vacancies: id, employer_id, title, salary_from, salary_to, currency, url, description

### dp_manager.py
Модуль для управления данными и выполнения запросов. Содержит:
Класс DBManager:
- get_companies_and_vacancies_count() - компании и количество вакансий
- get_all_vacancies() - все вакансии с деталями
- get_avg_salary() - средняя зарплата
- get_vacancies_with_higher_salary() - вакансии с зарплатой выше средней
- get_vacancies_with_keyword(keyword) - поиск по ключевым словам

## 🚀 Запуск проекта

1. Активируйте виртуальное окружение:

source .venv/Scripts/activate  # Windows
source .venv/bin/activate      # Linux/Mac

2. Запустите основное приложение:

python src/main.py

3. Выберите действие из меню:

1 - Список компаний и количество вакансий
2 - Список всех вакансий с деталями
3 - Средняя зарплата по вакансиям
4 - Вакансии с зарплатой выше средней
5 - Поиск вакансий по ключевому слову
0 - Выход

## 📊 Примеры запросов

1. Статистика по компаниям
Показывает количество вакансий у каждой компании-работодателя.

2. Детальная информация о вакансиях
Отображает все вакансии с указанием компании, должности, зарплаты и ссылки.

3. Анализ зарплат
Рассчитывает среднюю зарплату по всем вакансиям с указанием заработной платы.

4. Премиум вакансии
Находит вакансии с зарплатой выше среднего уровня.

5. Поиск по ключевым словам
Ищет вакансии по названию или описанию.
